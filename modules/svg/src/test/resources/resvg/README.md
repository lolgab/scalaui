Test fixtures taken from the resvg test suite (https://github.com/linebender/resvg, `crates/resvg/tests/tests`), licensed MIT OR Apache-2.0.
Each `.svg` is paired with the `.png` rendered by resvg at a width of 300 pixels. The selection covers every category with the cases scalaui matches.
Text cases are rendered with the Noto Sans fonts bundled in the `font` module.
